## 六、取证注意

1. 上传任何截图前，**检查是否带入账号、密钥、手机号、二维码**。本目录中的单屏聊天截图已裁去顶部含 `sk-` 密钥的一行。
2. 截图不要二次压缩或加滤镜，保持原始字节；需要对某处打码时，另存为新文件并在本表登记，不要覆盖原件。
3. 原始文件可放 `originals/` 并随仓库公开——原图比截图更有证明力；放进去之前只需确认图片本身不含隐私信息。
4. 截图之外，**导出一份 QQ 聊天记录文件**并附上，是这条证据链的最后一环：它能证明时间戳没有被截图工具修改。
