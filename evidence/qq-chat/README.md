## 二、关键事实：会话对象就是权利人本人

导出文件中 `chatInfo` 字段：

```json
{
  "name": "杯子Cup", "type": "private",
  "selfUid": "u_Z0qgpSAvwle3ycBq-aCdkg", "selfUin": "2023351165", "selfName": "杯子Cup",
  "peerUid": "u_Z0qgpSAvwle3ycBq-aCdkg", "peerUin": "2023351165"
}
```

`selfUin == peerUin == 2023351165`，`selfUid == peerUid`，即**这是 QQ 账号 2023351165 发给自己（收藏 / 文件传输助手式会话）的记录**。

因此：

- 导出文件名前缀显示为 `friend_`，是导出工具按「会话」命名所致，**不代表存在第三方**；
- 全部 128 条消息的发送者 uin 均为 2023351165，即**本人在自己的账号内向自己发送**；
- 这批图不是「别人发来的」，而是权利人本人 2026-11-06 起陆续发给自己留存的成品。
