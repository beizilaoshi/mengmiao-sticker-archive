## 二、为什么不放进仓库

1. **体积**：约 183 MB，不适合放进 Git 历史（Git 永久保存，无法真正瘦身）。
2. **隐私**：这是账号的**完整**聊天数据库，包含与所有人的全部往来内容，不只是这 22 张表情包。一旦公开无法撤回。
3. **无阅读价值**：内容加密，第三方（包括法院、平台审核）拿到也无法直接读出，只能通过 QQ 客户端导入查看。

## 四、想拿到可读的导出记录，应该这样做

当前这个包是「加密备份」形态，适合存档、不适合举证。**PC 版 QQ（NTQQ）可以直接导出明文记录**：

1. 登录 PC 版 QQ → 打开与「杯子Cup」的会话；
2. 右上角 `⋮` / `…` → **聊天记录** → 右上角 **导出消息记录**；
3. 格式选 **`.txt`**（纯文本，含精确到秒的时间与发送者）或 **`.mht`**（含图片，可用浏览器打开）；
4. 导出后**不要整份公开**——里面可能夹着其他私人对话。把文件放到本机，告诉我路径，我来做两件事：
   - 只抽取与这 22 张表情包相关的发送记录，生成 `evidence/qq-export/sticker-sends.txt`（可公开）；
   - 对整份明文导出计算哈希并登记，原件留在本机不推送。
