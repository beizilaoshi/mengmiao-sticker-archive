## 二、为什么有用

1. **两家服务商同时留痕。** 邮件同时经过网易（163）与腾讯（QQ）的服务器，时间由 `Received` 邮件头记录，任何一方都不是本机能篡改的。
2. **与 GitHub 相互独立。** 本仓库的 Git 提交时间来自本机时钟，理论上有争议空间；邮件时间来自服务商日志，二者相互印证时更难被推翻。
3. **可复核。** 需要时，可要求邮件服务商出具邮件头或收件日志；只要保留原邮箱不删信，链路就一直在。

## 三、更硬的做法（如需要，0 元）

- 在 QQ 邮箱网页端把该邮件**导出为 `.eml`**（含完整邮件头 `Received:`、`Message-ID:`、`Date:`），与本 PDF 一起存档；
- 把 `.eml` 的 SHA-256 也登记到本文件下方；
- 若将来做时间戳或公证，`.eml` 比页面截图更受认可。

## 四、校验

# 在仓库根目录执行
Get-FileHash evidence\email\2026-11-25-qqmail-59M.pdf -Algorithm SHA256
