# 可信时间戳待办 / Trusted Timestamp To-Do

这一页是给**你自己照着做**的操作单。做完之后，本目录会多出 `.tsa` 文件与《可信时间戳认证证书》PDF，仓库的时间证据链就闭环了。

> 现在的时间证据已经有三层（Git 提交、QQ 聊天记录、双端邮件头），缺的最后一环是：**证明这些文件在某个时刻之前就存在，且当时就是这些字节**。可信时间戳（TSA）就是干这个的，一次 10 元。

## 二、两条路，选一条

### 路线 A：网页申请（推荐，10 元/次，电脑上就能做）

1. 打开 **联合信任时间戳服务中心**：<https://www.tsa.cn>（知识产权保护专用入口：<https://ipr.tsa.cn>）
2. 注册 / 登录 → 实名认证（个人：姓名 + 身份证号 + 手机号，几分钟）
3. 进入「**时间戳申请 / 文件存证**」，上传上表第 1 个文件
4. 支付 **10 元**（支持微信/支付宝，按次计费，充 10 元起）
5. 系统当场生成两个东西，**都要下载**：
   - `xxx.tsa` —— 时间戳凭证本体（几 KB 的二进制，别用记事本打开改它）
   - `xxx_认证证书.pdf` —— 给人看的《可信时间戳认证证书》（含证书编号、时间、文件哈希）
6. 把这两个文件原样放进本目录，命名照下面「三」的格式

> 计费口径：基础电子证据时间戳认证 **10 元/次**；不同功能/取证时长价格不同，以网站公示为准（[联合信任知识库](https://m.tsa.cn/baike-page-7-c-14.html) 明确写明「最低只需 10 元/次」）。

### 路线 B：手机 App（顺手，适合以后随时取证）

1. 应用商店搜「**权利卫士**」（联合信任官方 App，iOS/Android 都有）
2. 实名认证 → 选「**文件存证**」或「录屏取证」
3. 手机录屏取证约 30 元起 / 电脑录屏 50 元起，**普通文件存证仍按 10 元/次**，按实际用时扣费
4. 出证同样是 `.tsa` + PDF 证书

> 这条路的好处：以后在网上看到有人盗图，**当场录屏取证**（点进店铺→商品页→价格→销量），一次几十块，比事后公证便宜得多。判例里 12 万+ 篇裁判文书用过可信时间戳。

## 三、盖完之后怎么入库

把文件放进本目录，命名格式：

```
evidence/timestamp/
├── 2026-11-26-MANIFEST.sha256.tsa
├── 2026-11-26-MANIFEST-证书.pdf
└── README.md          ← 本文件（补一行记录，见下）
```

`.tsa` 是二进制、PDF 是二进制，`.gitattributes` 里已声明 `*.pdf binary`，再加一行 `*.tsa binary` 就不会被换行改写。

然后在本文件末尾的「执行记录」表里补一行，并在 `TIMESTAMP.md` 的第四层（可信时间戳）写下证书编号与验证方式，最后：

```powershell
cd 'E:\私心\IP'
git add evidence/timestamp
git commit -m "evidence: 加盖可信时间戳（MANIFEST.sha256，证书编号 xxxx）"
git push origin main
```

## 四、别人（或法官）怎么验证

联合信任官网有公开验证入口 <https://www.tsa.cn>，上传 `.tsa` 文件 + 原始文件即可验证「是否匹配、何时盖戳」。也就是说：

- **文件被改一个字节** → 验证失败；
- **换个时间盖同一个文件** → 得到不同的戳，旧的仍然只证明旧时刻。

这正是「防篡改 + 防事后抵赖」的全部含义。
