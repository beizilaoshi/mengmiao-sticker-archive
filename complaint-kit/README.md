# 投诉包 / Complaint Kit

> **这套东西的用法：找到侵权内容 → 复制对应模板 → 填空 → 提交。**
> 全部真实信息（权利人、首发时间、仓库地址、哈希）已经**预先填好**，你只需要填「侵权链接 / 日期 / 哪张图」这几处，标了 `【】` 的就是待填。

---

## 一、三步走（每步都别跳）

### 第 1 步：先把证据冻住（5 分钟，最重要）

页面一删，证据就没了。**投诉之前**先做这三件事：

1. **截图**：侵权页面全屏截图，必须带上**地址栏 URL**、**发布者 ID/昵称**、**发布时间**、**点赞/销量**
2. **存页面**：浏览器 `Ctrl+P` → 另存为 PDF（比截图更难被质疑篡改）
3. **录屏**（电商店铺必做）：从首页点进商品页、看到价格和销量，全程录下来——用「权利卫士」盖时间戳更好，不盖也行，先有视频

### 第 2 步：选平台，抄模板

| 平台 | 去哪里投诉 | 用哪个模板 |
|------|-----------|-----------|
| 微信（公众号/视频号/表情包商城） | https://mp.weixin.qq.com → 帮助中心 → 侵权投诉 | [`02-平台模板.md`](02-平台模板.md) 第 1 节 |
| 抖音 / 快手 | App 内「举报」→ 知识产权；或 https://www.douyin.com/feedback | 第 2 节 |
| 小红书 | 笔记右上角「…」→ 举报 → 侵权 | 第 3 节 |
| 哔哩哔哩 | 视频页「…」→ 举报 → 侵权申诉 | 第 4 节 |
| 淘宝 / 天猫 / 闲鱼 | https://ipp.alibabagroup.com （阿里知产保护平台） | 第 5 节 |
| 拼多多 | 商家后台 → 知识产权投诉 → 或 https://ipp.pinduoduo.com | 第 5 节 |
| 微博 / 知乎 / 贴吧 / 豆瓣 | 内容页「举报」→ 侵权 | 第 6 节 |
| GitHub / Twitter / Pinterest / Etsy | 各自 DMCA 表单 | 第 7 节（英文） |

### 第 3 步：一次性交齐，别补三次

平台客服每让你补一次材料，处理时限就重置一次。**第一次就交齐**：

- [ ] 身份证正反面照片（加水印「仅供版权投诉使用」）
- [ ] [`01-权属声明.md`](01-权属声明.md) 填好后粘贴进表单 / 或存成 PDF 附件
- [ ] 侵权页面截图 + PDF 快照
- [ ] 首发证明：GitHub 首次提交页截图
- [ ] （电商）比对图：左原图右侵权图，并排拼一张

## 四、这套材料里都装了什么

```
complaint-kit/
├── README.md          ← 本文件：三步走 + 权属速查表
├── 01-权属声明.md      ← 通用权属说明，填空即用（几乎所有平台都吃这一套）
├── 02-平台模板.md      ← 8 类平台的具体模板
├── 03-证据清单.md      ← 截图要截什么、附件怎么命名、比对图怎么做
├── 04-投诉记录表.csv   ← 每次投诉记一行，方便催办和做「多次通知」证据
└── 05-驳回应对.md      ← 被驳回时怎么说
```

完整的「为什么这么写」的说明见仓库根目录 [`COMPLAINT-TEMPLATES.md`](../COMPLAINT-TEMPLATES.md)。

## 五、一句提醒

**态度要平，事实要硬。** 投诉不是吵架：平台审核员一天看几百条，越短越清楚越容易过。模板里的「诉求」永远只写三件事——删除内容、处理账号、保留日志。赔偿的事，等对方是商家再说。
