## 三种场景的「侵权事实」段落（替换第三段）

### A. 搬运 / 冒充原创（内容平台最常见）

```
被投诉方于【日期】在【平台】发布的【链接】，直接搬运/轻微修改了本人作品，
并在标题与正文中声称"原创""自制""作者本人"，误导公众认为其为著作权人，
同时覆盖/去除了本人署名。该行为侵犯本人的署名权、复制权与信息网络传播权，
并构成不正当竞争意义上的混淆。
```

### B. 商用（店铺、带货、印制商品）

```
被投诉方将本人作品印制于【手机壳/抱枕/贴纸/服饰/鼠标垫】等商品上公开销售，
商品页链接【链接】，售价【__】元，已售【__】件（截图见附件）。
该行为属于对本人作品的复制与发行，且以营利为目的、获利明显，
已超出任何合理使用范围，侵犯本人的复制权、发行权与获得报酬权。
```

### C. 二次修改 / 换色 / 拼接（衍生但不实质改变）

```
被投诉方对本人作品进行了【换色/裁剪/局部重绘/与其他元素拼接】后发布，链接【链接】。
改动未形成新的独创性表达，仍保留了本人作品的核心独创性特征
（角色造型、异色瞳、猫耳与樱花金铃蓝缎带装饰、构图与配色）。
该行为属于对本人作品的改编与信息网络传播，未经许可，构成侵权。
```
