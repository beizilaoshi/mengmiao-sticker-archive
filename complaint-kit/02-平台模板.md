## 5. 电商：淘宝 / 天猫 / 闲鱼 / 拼多多 / 京东

**入口**
- 阿里系（淘宝/天猫/闲鱼）：**阿里知产保护平台** https://ipp.alibabagroup.com → 注册 → 提交权属 → 发起投诉
- 拼多多：https://ipp.pinduoduo.com 或商家后台 → 知识产权投诉
- 京东：https://ipr.jd.com

**注册时提交的权属材料**（一次提交，以后复用）
1. 身份证
2. 权利证明：**首发链接（GitHub）+ 首次提交页面截图 + `MANIFEST.sha256`**
3. 作品样本：22 张图的缩略总览（用仓库 `preview.jpg`）


## 9. 行政举报（侵权规模大时）

- **12321** 网络不良与垃圾信息举报：https://www.12321.cn
- **著作权行政管理部门**：当地版权局（广东：广东省版权局 020-87197981）
- **公安**：仅限涉嫌犯罪（如大规模盗版牟利）时，12377 或当地网警报案
