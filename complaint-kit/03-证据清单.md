# 03 · 证据清单与制作方法

> 投诉能不能过，八成看这一步。**截图不规范 = 白投诉**。

---

## 一、侵权页面要截哪些图（缺一项就可能被驳回）

| # | 截什么 | 为什么 |
|---|--------|--------|
| 1 | **整屏截图**，含浏览器地址栏的完整 URL | 证明「这个链接确实有这个内容」 |
| 2 | **发布者信息**：昵称 + ID（抖音号/小红书号/店铺名/公众号原始ID） | 平台要精确定位账号 |
| 3 | **发布时间**（点开「展开」或悬停） | 比对谁先谁后 |
| 4 | **数据**：点赞/收藏/播放/销量/售价 | 证明影响力或商业获利 |
| 5 | **侵权内容本体**（图片放大截一张） | 做同一性比对 |
| 6 | 浏览器 `Ctrl+P` → **另存为 PDF** | 比截图更难被质疑篡改 |

**命名规范**（审核员一眼看懂）

```
04-1-侵权页面全屏.png
04-2-发布者信息.png
04-3-发布时间.png
04-4-商品页-售价与销量.png
05-并排比对图.jpg
06-侵权页面快照.pdf
```

## 二、同一性比对怎么做（这是最硬的证据）

### 方法 A：SHA-256 完全一致（最有力，说明是原文件直传）

```powershell
# 下载对方发布的图片，与原图比哈希
Get-FileHash '.\对方图片.jpg' -Algorithm SHA256
Get-FileHash 'E:\私心\IP\assets\01-乖宝宝.jpg' -Algorithm SHA256
```

两边哈希完全相同 → **就是同一个文件**，无需再论证相似度。
（注意：平台二次压缩后哈希会变，此时用方法 B。）

### 方法 B：并排比对图（哈希变了但图一样时用）

做一张 A4 横版图：**左原图 / 右侵权图 / 下方写结论**。

```
┌──────────────┬──────────────┐
│  本人原图      │  侵权内容     │
│  01-乖宝宝    │  某店铺商品页  │
│  2026-11-25   │  2026-12-03  │
└──────────────┴──────────────┘
   核心特征一致：异色瞳（左金右蓝）、螺旋呆毛、猫耳、
   樱花+金铃+蓝缎带、蓝白和风服装、比例与构图相同
```

### 方法 C：三处特征点放大（对方改过色/加过滤镜时）

在原图和侵权图上各取 3 个相同位置局部放大（眼睛、铃铛、发饰），拼成 2×3 网格，
证明「改动没有改变独创性表达」。

> 仓库 [`evidence/qq-chat/`](../evidence/qq-chat/) 里有现成的复现脚本思路：
> 缩放到同一尺寸后算 RGB 平均绝对差，差值 1–2 即视为同一张图。

## 四、身份证照片怎么处理

1. 正反面拍照，**加半透明水印**：「仅供版权投诉使用 · 2026-11 · 龚震宇」
2. 水印要压在证件上但不遮住姓名和证件号
3. 只提交给平台官方表单，**不要**发给私信里的「客服」

---

## 五、证据保全的底线（不要踩）

- ❌ 不要 P 图「美化」证据，哪怕只是为了更清楚——被识破全盘作废
- ❌ 不要只存截图不存 URL，链接失效后截图证明不了出处
- ❌ 不要先私信骂人再投诉，对方可能抢先删帖并反诉名誉侵权
- ✅ 所有原始文件保留原样，别重命名别压缩
- ✅ 每次投诉后保存**回执编号 + 处理结果截图**（见 `04-投诉记录表.csv`）
